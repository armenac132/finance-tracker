# finance-tracker

Personal finance tracking app — bank accounts, investments, credit, loans, assets.

Built as a learning vehicle for:
- Microservices architecture (event-driven, polyglot, independently deployable)
- .NET Blazor WebAssembly frontend
- GitHub Actions CI/CD
